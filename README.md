# Leilões TDSat

## Sobre o projeto
Sistema desktop desenvolvido para uma casa de leilões, com o objetivo de informatizar
suas rotinas. A aplicação permite cadastrar produtos (nome e valor), listar os produtos
cadastrados e controlar o status de cada item ("A Venda" ou "Vendido"), armazenando as
informações em banco de dados.

## Tecnologias utilizadas
- Java (aplicação desktop com interface gráfica Swing)
- MySQL (banco de dados `uc11`, gerenciado pelo MySQL Workbench)
- JDBC com MySQL Connector/J (conexão entre Java e MySQL)
- Padrão DAO/DTO para acesso a dados
- NetBeans IDE
- Git e GitHub (versionamento)
